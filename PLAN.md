# План Tutorina

## Принятая концепция

Публичная доска свободных слотов и закрытая админка. Посетитель только смотрит
расписание, все статусы и занятость меняет администратор. Общение и договорённости
происходят вне сайта. Участники и их персональные сведения не хранятся.

## Реализовано

- [x] Новая начальная схема БД: административные учётные записи, сессии, слоты.
- [x] Публичная доска будущих опубликованных слотов со свободными местами.
- [x] Админка создания, переноса, отмены, завершения, публикации и удаления слотов.
- [x] Числовой учёт занятости с ограничениями вместимости.
- [x] Вход по техническому логину вместо email и смена пароля.
- [x] Удаление заявок, профилей, фотографий, кабинетов преподавателей и связанных API.
- [x] Удаление прежних миграций, шифрования заявок и конфигурации фотохранилища.
- [x] Новая конфигурация Compose и документация.

## За пределами текущей версии

- Повторяющиеся слоты и массовые операции расписания.
- Отдельная модель ресурсов, если понадобится несколько независимых расписаний.
- Подготовка инфраструктуры к публикации по [SECURITY.md](SECURITY.md).
